> A clean, functional browser-based calculator built with HTML5, CSS3, and Vanilla JavaScript — supporting arithmetic operations with a responsive button layout.

---

## ✨ Features

- ➕ **Basic Arithmetic** — Add, subtract, multiply, divide
- 🗑️ **Clear Display** — Reset input instantly
- 📱 **Responsive Layout** — Works on all screen sizes
- ⚡ **No dependencies** — Pure HTML/CSS/JS

---

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| **HTML5** | Calculator structure and buttons |
| **CSS3** | Grid layout, button styling |
| **JavaScript (ES6+)** | Arithmetic logic, event handling |
